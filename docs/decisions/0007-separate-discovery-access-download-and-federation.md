# ADR-0007：分离发现、阅读、下载与联邦发布

状态：已接受

日期：2026-08-05

## 背景

“公开一本书”可能表示公开书名和封面、允许在线阅读、允许下载文件，或者把相关动态发送到联邦网络。这些行为的版权、隐私和安全影响完全不同，不能由一个 `public` 布尔值同时控制。

## 决策

系统分别管理以下四层策略：

1. **元数据发现**：谁可以查看书名、作者、封面和简介等书目信息。
2. **内容阅读**：谁可以通过受控阅读接口访问正文资源。
3. **文件下载**：谁可以获得完整原文件或允许下载的衍生文件。
4. **联邦发布**：哪些公开书目或社交活动可以发送到远程实例。

公开元数据不授予阅读或下载权限；允许在线阅读也不自动允许下载原文件。联邦发布只能引用本地已经允许公开的字段，但本地公开不会自动触发联邦发布。

所有内容访问在返回资源前都必须由服务端重新授权，不能只依靠搜索索引、前端隐藏或签名 URL 的存在。

## 结果

书库可以安全地公开目录、书评和书单，同时保留文件访问控制。未来对接 OPDS 和 ActivityPub 时也能分别生成目录获取链接与社交活动，避免协议之间产生隐式授权。
