# ADR-0001：书库是唯一协作与隔离边界

状态：已接受

日期：2026-08-05

## 背景

早期讨论同时出现了组织、工作区、书库和全部图书等概念，用户难以判断它们之间的区别，也会导致权限与数据归属层级过多。

## 决策

- 使用 `Library（书库）` 作为唯一的协作、数据隔离和权限边界。
- 私人书库与共享书库使用相同模型。
- 用户可以属于多个书库。
- “全部图书”只是书库中的查询视图，不是独立实体。
- Collection 或 Shelf 仅用于分类，不复制 Item 或 Blob。

## 结果

权限、配额、搜索范围、成员关系和审计都有明确租户边界。未来联邦身份属于用户和实例，不把 Library 直接等同于联邦实例。
