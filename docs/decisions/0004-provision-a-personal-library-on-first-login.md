# ADR-0004：首次登录时默认创建个人书库

状态：已接受

日期：2026-08-05

## 背景

FolioHarbor 同时支持公开注册、邀请注册、本地账户和 OIDC。若不同入口产生不同的书库状态，用户会遇到不一致的首次使用体验，也难以判断私人内容应该放在哪里。

## 决策

- 实例默认启用个人书库自动创建。
- 用户首次成功登录时，系统以幂等方式创建一个个人书库并授予其 owner 身份。
- 本地账户、受邀账户和 OIDC 首次登录采用相同规则。
- 受邀用户可以同时拥有个人书库并加入邀请指定的共享书库。
- 每个用户在一个实例中最多拥有一个由系统自动配置的个人书库。
- 实例管理员可以关闭自动创建；关闭只影响尚未创建的个人书库，不删除或降级已有书库。

## 结果

默认部署没有空白首页或私人内容归属不明的问题；企业部署仍然可以关闭个人书库，只提供管理员管理的共享书库。创建流程必须能够安全重试，不能因重复登录产生多个个人书库。
