# ADR-0008：同一书库的相同文件上传保持幂等

状态：已接受

日期：2026-08-05

## 背景

网络重试、移动端恢复上传或用户重复选择文件都可能让同一个原文件被多次提交。如果每次都创建馆藏条目，书库会出现无意义重复；如果跨书库直接复用同一个 Item，又会破坏权限、来源和生命周期隔离。

## 决策

- 上传完成哈希计算后，如果同一书库已有引用相同原始 Blob 的有效 Item，则返回已有 Item，默认不创建新的 Holding、Item 或书架条目。
- 重复请求仍记录上传尝试、请求主体、时间和判定结果，便于审计和排查客户端重试。
- 不同书库上传完全相同的文件时分别创建各自的 Item；是否物理复用 Blob 由实例去重范围配置决定。
- 哈希相等只用于字节级去重。标题、作者、ISBN 或正文相似只产生书目匹配候选，不能自动合并 Work、Expression 或 Manifestation。
- 第一版不提供“强制把相同文件创建为额外副本”的普通操作。将来如果需要表达多份独立授权，可以增加显式且经过授权的高级操作。

## 结果

上传接口可以安全重试，书库不会因重复请求产生重复条目；跨租户仍保持清晰的逻辑副本和权限边界。书目实体合并继续通过独立、可审计的等价关系与人工确认流程完成。
