# ADR-0009：从端到端 EPUB 纵切开始实施

状态：已接受

日期：2026-08-05

## 背景

FolioHarbor 同时涉及身份、书库、权限、书目、存储、导入、阅读、搜索、移动客户端和联邦。将全部能力写入一份实施规格会失去可审阅性；只建设平台基础又无法及早验证真正的私人图书馆流程。

## 决策

第一份正式规格采用端到端最小纵切，覆盖：

```text
本地注册与登录
→ 自动创建个人书库
→ 邀请第二位用户
→ 使用内置角色授权
→ 上传 EPUB
→ 建立标准书目、馆藏和副本
→ 浏览书库
→ 在线阅读并保存进度
→ 按权限下载原文件
```

该纵切从第一天包含显式数据库迁移、PostgreSQL RLS、统一授权、审计和后台导入任务。它只实现 EPUB 与本地存储，但通过稳定接口为后续 S3、TXT、PDF、OIDC、Meilisearch 和移动客户端保留扩展点。

以下能力不进入第一纵切：旧数据迁移、全文搜索、批注、联邦、公开目录、自定义角色以及完整管理后台。

## 结果

第一阶段能够用两个真实用户验证书库边界、权限、文件生命周期和阅读链路。后续能力可以围绕已经运行的领域模型分批增加，而不是先构建无法验证的大型基础平台。
