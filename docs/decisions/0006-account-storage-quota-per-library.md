# ADR-0006：按书库逻辑用量计算存储配额

状态：已接受

日期：2026-08-05

## 背景

实例默认允许公开注册。如果没有存储边界，单个用户或意外批量导入可能耗尽整个实例。另一方面，Blob 可以跨书库物理去重，因此直接按磁盘占用计算会让租户用量取决于其他书库的内容，既不可预测也可能泄露去重信息。

## 决策

- 第一版必须支持书库级存储配额。
- 配额按书库通过 ItemAsset 引用的原始文件和永久衍生文件的逻辑字节数计算。
- 多个书库引用同一 Blob 时，各自计算完整逻辑用量；物理去重只作为实例内部优化。
- 临时解包、LRU 缓存和可重建搜索索引不计入书库配额。
- 实例管理员可以设置默认书库配额、覆盖特定书库的配额，以及单文件上传上限。
- 本地存储和对象存储适配器必须提供独立容量保护；达到安全余量时，即使书库尚未超额也暂停新写入。
- 上传流程在接收前进行预计用量检查，在内容落盘和事务提交时再次确认，避免并发上传突破配额。

## 结果

公开注册拥有基本的资源滥用防线，书库用量稳定且可解释，实例仍能从 Blob 去重中节约真实磁盘空间。具体默认数值将在部署规格中根据目标设备和单文件限制一起确定。
