# ADR-0005：第一版只开放内置角色

状态：已接受

日期：2026-08-05

## 背景

FolioHarbor 需要企业级的数据权限能力，但任意自定义角色会显著扩大授权组合、冲突处理、管理界面和回归测试的范围。第一版需要优先保证隔离与授权判断正确，而不是追求角色数量。

## 决策

- 第一版只开放 `owner`、`editor`、`reader` 三个内置角色。
- 内置角色的权限集合由版本化程序定义并经过完整授权测试，普通用户不能修改。
- 数据库使用独立的权限目录、角色和角色权限关系，不把角色能力硬编码成单一枚举判断。
- 统一授权引擎只识别稳定的动作标识，例如 `library.manage`、`holding.view`、`item.read` 和 `resource.manage_acl`。
- 第一版不提供创建、编辑或删除自定义角色的界面与 API。
- 资源级授权不依赖自定义角色，可以继续对特定主体授予受控资源访问权。

## 结果

第一版可以集中验证默认拒绝、书库隔离、资源授权和审计链路。未来增加自定义角色时可以复用既有权限模型，但仍需单独设计权限冲突、角色复制、角色删除和管理者锁定规则。
