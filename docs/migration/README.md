# 旧数据治理与迁移

旧 `ebooks-go` 数据迁移安排在 FolioHarbor 私人图书馆核心闭环完成之后。

迁移必须遵循以下阶段：

1. 只读盘点与快照标识。
2. 正文规范化和章节包含关系验证。
3. 生成保留、合并、拒绝和人工复核清单。
4. 将旧书目映射到 Work、Expression、Manifestation、Holding 和 Item。
5. 将治理后的正文包装为新系统支持的内容形态。
6. 写入新数据库并校验数量、哈希、顺序和可读性。
7. 保留旧标识符到新 UUID 的迁移映射与审计报告。

本目录后续将保存规则规格、演练报告、回滚策略和正式迁移运行手册。
